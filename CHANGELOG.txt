RustOS change list. Newest on top. Installed systems show this in "What's new" after an update.
Each "== RustOS x.y ==" line starts a version. publish.bat adds a line under the newest version for you.

== RustOS 2.10 ==
- New: .debug selftest checks every RustOS feature (updates, desktop, EXE Center, boot screen, iPad mode, antivirus) and saves a PASS / WARN / FAIL list you can share
- New beta update channel: test versions reach testers first. Join with  sudo rustos-channel beta  (or .debug mod beta on, or Update Center), leave with  sudo rustos-channel stable
- Update Center: choose normal or beta updates
- ARM / iPad image: much smaller startup file so it boots in UTM with less memory

== RustOS 2.9 ==
- New RustOS EXE Center app: a real window with a game library that shows each program's own icon, search, favourites, drag and drop, Run and Run as game, settings per program (always game mode, FPS counter, extra start options, error log), one-click downloads (Visual C++, DXVK, DirectX, .NET, fonts and more), DLL installer, setups and runtimes pages, tools (C: drive, Windows settings, task manager, stop all) and a live log. The classic menu is still there
- RustOS boot screen: the RustOS logo with a warm glow and a progress bar while the PC starts (also asks for the disk password nicely), and a RustOS background for the GRUB boot menu. Turned on once by this update. Turn it off with: rustos-bootsplash off
- 20 more .debug commands: boot, temp, battery, top, watch, wine, packages, history, restore, clean, speed, bench, usb, ports, display, sound, bluetooth, env, crash
- More .debug fixes: dns, time, fonts, icons, initramfs, grub, bootsplash, mirrors, exe
- New mod: .debug mod bootsplash on/off

== RustOS 2.8 ==
- New .debug command in the terminal: type  .debug help  to see everything
- .debug info, update, logs, services, net, gpu, disk: see what your PC is doing and why something fails
- .debug report saves everything into one text file you can send when you ask for help
- .debug fix: quick fixes for a frozen panel, no sound, stuck network, pacman lock, package keys, iPad mode, Flatpak
- .debug mainmod: the main mod menu. Turn tweaks on and off (dark theme, no animations, accent color, colorful prompt, no banner, iPad mode, auto updates, programming tools)
- Make your own mods: .debug mod new <name> makes a small script, then .debug mod <name> on
- Tab completion for .debug
- ARM edition: much smaller startup file, so it boots on iPads with less memory (fixes "Failed to load initrd")

== RustOS 2.7 ==
- New iPad mode: an iPad-style home screen with a floating dock, app grid, thin top bar, iPad-style icons, windows that open full screen and a touch keyboard. Works with mouse and keyboard too, so you can try it on any PC without a touchscreen
- Button to open it: "iPad Mode" in the menu, on the desktop, in the taskbar and in the Update Center, or press Meta+Ctrl+T. Turn it off the same way and your old desktop comes back exactly as it was
- Touchscreen support for PCs and iPad: on-screen keyboard (also on the login screen), swipe up from the bottom edge to see open windows, "Touch only" option that keeps your normal desktop, auto-rotate support
- RustOS Apps has a much bigger list (50+ apps in groups: office, internet and chat, music and video, pictures, programming, games, tools) and you can tick across groups before installing
- Many more programs ready out of the box: man pages, htop/btop, 7-Zip and unrar, video and image thumbnails, more codecs, KDE extras (phone file access, calculator, disk usage), Papirus icons
- The ARM edition now matches the PC edition: same packages (Bluetooth, power profiles, partition manager and so on), same language and keyboard questions at first start, same settings; it only leaves out what does not exist for ARM
- Safer updates: a package name that does not exist can no longer break an update for everyone

== RustOS 2.6 ==
- New RustOS EXE Center (replaces Windows App Support): a folder (EXE-Center) for your Windows files with Setups, Runtimes (.NET, Visual C++, DirectX), DLLs and Programs; install a setup like cs1.6 setup.exe, install runtimes and DLLs, run programs and games, all from one window
- Right-click an .exe: "Add to RustOS EXE Center". Double-click a .dll to install it
- "Remove Windows support" button in the EXE Center (Wine is the engine behind .exe support, so it is only removed if you ask)
- ARM edition is lighter: leaner package list, compressed-RAM swap, journal in RAM, weekly TRIM

== RustOS 2.5 ==
- RustOS for iPad and other ARM devices (experimental): an ARM disk image for UTM, built by GitHub; update channel for ARM added
- On ARM, Windows .exe support and Steam are switched off with a clear message (they need an Intel or AMD PC)

== RustOS 2.4 ==
- Windows programs (.exe): double-click an .exe, .msi or .lnk and RustOS runs it with Wine (it offers to install Wine the first time)
- Warns before running things that are known not to work well (anti-cheat games, Microsoft Office, Adobe)
- Right-click an .exe, choose "Run as game" for GameMode and the MangoHud overlay
- Undo an update: RustOS saves a restore point before every update and the Update Center can go back to it
- Installer: choose your language and keyboard layout
- Installer: choose the NVIDIA driver while installing
- First login: pick the apps you want (Office, VLC, printing, GIMP, OBS, Bottles, gaming)
- New "Switching from Windows" helper: open your Windows files, run .exe files, find replacement apps
- New Education Center: PDF reader and tools, shortcuts for Canva, Google Docs, Google Classroom, Microsoft 365, Khan Academy and Duolingo, plus Anki, Zotero, Obsidian, Scratch, GeoGebra, Calibre and more
- New RustOS Antivirus (ClamAV): scan a folder, your home folder or the whole PC, right-click any file or folder and choose "Scan for viruses", with a quarantine
- publish.sh for publishing from RustOS itself (publish.bat stays for Windows)
- publish.bat: the one-line message is now optional

== RustOS 2.1 ==
- The RustOS update channel is online: updates come from GitHub and show a popup

== RustOS 1.1 ==
- Update popup after every update, with a What's new button and a Restart now button
- RustOS Update Center in the app menu: check, install, history, automatic updates on or off
- RustOS Gaming Setup: Steam, GameMode, MangoHud, Gamescope, Lutris, Heroic, ProtonUp-Qt, Discord
- Gaming setup picks the right graphics driver for AMD, Intel and NVIDIA cards
- Lighter and faster: file indexer off, smarter memory and disk settings, smaller logs, quicker shutdown
- Performance mode in the battery menu (power-profiles-daemon)

== RustOS 1.0 ==
- First version: Arch base with pacman, KDE Plasma, RustOS logo, easy installer, dual boot, boot loader choice
- Automatic daily updates and the signed RustOS update channel
